# 基于高云FPGA的动态强窄带干扰检测与抑制系统

基于高云 ACG525 / GW5A-LV25 的动态强窄带干扰检测与抑制原型。电脑发送数字混合样本，FPGA 完成在线分析、检测、系数构建和连续滤波，实际输出经 UART 回传。

## 项目范围与实现

- 50 MHz 工作时钟，32 kHz 采样率；512 点主检测与 1024 点辅助校频。
- 近邻联合估计减轻谱峰相互影响；最多四个活动干扰中心、三个配置组，每组至多两个成员，支持两对双峰或两单加一双等组合。
- 641 抽头对称合并 FIR、后台系数构建、三库存储及 32 样本渐变；配置等待时样本通路持续运行。
- 输入目标应具有较分散、平滑的频谱；不适用于必须保留的合法强单音。当前没有 ADC 或射频接收前端。

## 快速开始

1. 在 Windows 安装 Python 3.12，进入 `代码`，运行 `SETUP_PYTHON.bat`。
2. 无需连接板子，可运行 `.venv\Scripts\python.exe -B verify_delivery.py` 检查交付文件，或运行 `validation\RUN_VERIFY.bat` 复算报告的配对误差、分量指标、切换与子系统资源数据。
3. 在 Gowin 教育版 1.9.11.03 打开 `代码/c4/pro_v2.gprj`，或运行 `代码/c4/run_build.bat`。安装位置不同时设置 `GW_SH`。保留工程中的 CPU/SSPI GPIO 及 hold 修正选项。
4. 按代码 README 中的 Flash 步骤烧录。接通供电及板上 UART，运行 `代码/RUN_C4_GUI.bat`，选择串口，配置输入后手动开始收发。

固件为 `代码/c4/ACG525_C4_V32_512_OLED.fs`。重建输出位于 `代码/c4/impl/pnr/pro_v2.fs`，不要把既有位流的通过记录当作本次重新构建结果。

## 启动文件

以下文件均位于`代码/`目录。

| 启动文件 | 用途 | 打开后是否自动收发 |
| --- | --- | --- |
| `RUN_C4_GUI.bat` | 通用上位机，可调整输入并使用1024离线对照 | 否，手动点击开始收发 |
| `RUN_RECORDED_CONTROL.bat` | 预载无附加干扰的实录输入 | 否，手动点击开始收发 |
| `RUN_RECORDED_DRM.bat` | 预载实录目标叠加人工干扰输入 | 否，手动点击开始收发 |
| `RUN_RECORDED_PAIRED_TEST.bat` | 选择板上UART后依次执行上述两组真实收发，结束后显示加干扰组结果 | 是，无需在GUI再点开始 |
| `SETUP_PYTHON.bat` | 首次建立Python环境并安装依赖 | 否，不连接板子 |

`python_env.cmd`由启动文件内部调用。硬件构建、输入自检、报告复核与旧记录回放入口位于各自子目录，详见代码README。

## 结果如何理解

实录目标叠加人工干扰、非正弦调幅两项数字板测，相对同输入 1024 **软件参考**的全段 NRMSE 分别降低 17.60% 和 22.61%。两组含中点探针的配对仿真分别降低 34.96% 和 32.38%，不是这两项板测。稳定段参考可能更优；详细输入、区间、失败条件与原始记录见报告和验证目录。

1024 对照不是另一套已上板的整机。离线脚本耗时不代表 FPGA 延迟。运行复算脚本也不等于重新进行 RTL 仿真、P&R 或板测。
