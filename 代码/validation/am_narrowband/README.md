# AM窄带干扰数字板测与同输入1024参考

本目录补齐报告非正弦AM实验的冻结输入、原始UART板测记录、1024软件输出及数值复核。现有固件、RTL和上位机源码均未改动；本次整理只重算已有数组，不重跑检测器、RTL、串口或Gowin流程。

在代码包根目录执行：

```text
python -B validation/am_narrowband/verify_metrics.py
```

仅需已安装的numpy。命令校验文件哈希、样本连续性、UART帧计数、两路同输入及固定对齐，再从原始实际回传重算NRMSE；结果写入本目录`verification_result.json`。也可在任意工作目录以脚本绝对路径运行，运行时只使用本代码包的相对文件，不依赖本机D盘的支撑材料目录。该命令不是新板测或新性能实验。

## 固定条件与结果

- 32 kHz、16000点、0.5 s；输入ID为`701f2becab0b`，与报告上位机截图一致。
- 沿用时间差扫描基准目标和噪声，四个载频为2311.3、2436.3、4972.7、5097.7 Hz；出现100/101/108/109 ms，消失350/360/370/380 ms。
- 每路采用10 Hz、深度0.3的调幅包络，活动段功率与原正弦对照匹配；它包含载波与边带，不代表任意非正弦或宽带噪声输入。
- 以`prepared/components.npz`中的原始目标为离线参考，不包含噪声及干扰。两路均固定对齐320样本、10 ms，不拟合增益或补零。
- 公共全段源0～490 ms：板端NRMSE 206.572005%，1024软件参考266.907439%，相对降低22.605377%。
- 稳定源240～320 ms：板端40.200869%，参考37.377557%，本方案在这个区间误差较高。
- 原始UART记录有16000连续输入/输出，250个64点样本帧及15个状态帧；243个主观测，17次提交。实际输出与上板前已保存的完整核RTL输出逐样本相同。

全段误差较大，结果用于说明该受控调幅输入下的相对动态恢复收益，不证明所有暂态或频段都满足20 dB/1 dB指标；本例没有独立中点探针。1024是有限精度软件数值参考，额外分析与系数准备等待取零，调度与板端不同，不是第二套板端硬件。

## 文件与复现边界

- `prepared/`：可在通用上位机“导入WAV/NPY”中加载`input.wav`；保持`components.npz`和`source_metadata.json`等配套文件在同目录。导入不自动收发。
- `board_capture/`：真实串口采集的原始元数据、输入输出、逐样本CSV和解码状态CSV，按原始字节保存。原始元数据中的历史路径仅溯源，不是运行依赖。
- `reference/`：同输入冻结1024软件输出、决策和统计。数值实现已经包含在包内`comparison_ui/reference_1024.py`及`validation/recorded_1024_reference`；本复核命令不会执行该算法。
- `rtl_evidence/`：此前完整核RTL输出和原运行日志，用于检查与实际板端输出相等，不冒充新仿真。
- `provenance/`：原准备/预检记录及原脚本文本。它们属于上板前的历史阶段，保留其中`board_experiment_performed=false`及原路径；不能直接作为新的执行入口。新板测事实以`board_capture/capture.json`为准。
- `manifest.json`：本目录冻结文件及已存在数值实现、主机收发模块的哈希绑定。`expected_results.json`给出原成绩，复核从样本重新计算，而不是直接打印原成绩。
